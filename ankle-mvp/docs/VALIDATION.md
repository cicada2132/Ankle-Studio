## 확인한 항목

- 평행선 0°, 10° 기울기, 역순 점, 수직선 90°.
- 같은 점으로 만든 선, 비유한 값, 잘못된 좌표 입력 거부.
- Lateral 3-4-5 픽셀 거리와 mm/px 환산. 보정 없으면 mm=null.
- 정상 ROM 110° / 제한율 0%, 예제 ROM 55° / 제한율 50%.
- 27.5°, 55°, 82.5° 및 각 경계의 전후 값에 대한 등급 후보.
- 잘못된 ROM 입력, 표준 초과 경고와 0% 하한.
- AI 점별 상태로 전체 검수 상태 재계산. 모델이 보낸 좌표 폐기.
- AI/법령 인증정보 없음, 네트워크·HTTP·JSON 응답 오류 처리.
- 판례 단건/다건 응답 정규화 및 검색 결과 중복 제거.
- 실제 로컬 HTTP 서버의 정적 화면 파일 반환과 OC 미설정 응답.
- `.env`, 서버 소스 및 상위 디렉터리 접근 차단; 다른 출처 요청 차단.
- 최소 DOM 대역을 사용한 UI 상태 회귀: 수동 확인 후 계산, 확대 시 각도 유지, Undo 후 측정값 무효화, 촬영 방향 변경과 보정 상태.

## 검증 의미의 한계

DOM 대역은 실제 브라우저 렌더링이나 마우스 좌표 정확도를 검증하지 않습니다. `tests/browser.cjs`는 추후 Chromium이 있는 환경에서 실행할 회귀 스크립트이며 이 기록에서는 통과로 계산하지 않았습니다. 화면 스크린샷이나 의료영상 검수 정확도 결과는 생성하지 않았습니다.

API 응답 테스트는 가짜 fixture를 사용합니다. 실제 응답의 현재 정책, 이용권한 및 모델별 호환성은 키 설정 후 검증해야 합니다. 이 앱을 임상·법적 최종 판정에 사용한 검증 결과는 없습니다.
