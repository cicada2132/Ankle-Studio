# 다음 개발자가 확인할 내용

현재 버전: 발목 수동 작도 MVP v1.0.0

## 기존 저장소 통합

- 기존 저장소 ZIP 또는 `run_measure.py`, `measure_prompt.txt`, 요구사항/실행구조를 확인한 뒤 연결한다.
- 기존 척추 측정 및 M1~M4를 삭제하거나 대체하지 않는다.
- 척추용 압박률 공식과 산재/보훈 법령 규칙은 검증된 근거와 적용일을 확보한 뒤 별도 모듈로 구현한다.

## 이번 버전의 남은 검증

- 본인 계정의 API 키/모델로 실제 영상 검수 연결 확인.
- 실제 `LAW_API_OC`와 승인된 법령/판례 API 권한으로 실서비스 호출 확인.
- 비식별 실제 영상 및 전문가 작도 기준을 사용한 해부학적 검수 정확도 평가.
- 도형 연습과 mock 응답 테스트는 임상 성능 평가로 간주하지 않는다.
- 임상 활용을 원하면 촬영 프로토콜, 방향표시, 보정 방식 및 측정 반복성을 정의한다.

## 추후 확장

- JSON 기록 불러오기 및 원본 SHA-256 매칭.
- 원본, 최초 점, 수정점, 검수 결과를 묶는 개인용 로컬 프로젝트 저장 형식.
- 판례별 수치·측정 대상·측정방법·판결 채택 여부를 근거 문장과 함께 검토하는 구조화 도구.
- API 응답에서 임의 퍼센트를 곧바로 대상 장해율로 사용하지 않는다.
- 정책별 법령 개정 이력과 사건 적용일 선택 기능.
