발목 장해 기준은 \*\*“정상 발목 110° 중 실제로 몇 도를 잃었는가”\*\*로 이해하면 가장 쉽습니다. 보훈 장해평가용 계산기로 만들 때도 이 구조가 핵심입니다.

### 1. 정상 발목 = 총 110°

국가유공자법 시행규칙상 발목의 정상 운동범위는 다음과 같습니다. [법제처](https://www.law.go.kr/flDownload.do?bylClsCd=110201\&flSeq=151144423\&gubun=\&utm_source=chatgpt.com)

| 움직임             | 정상각도     |
| --------------- | -------- |
| 배굴 — 발등 쪽으로 올림  | 20°      |
| 척굴 — 발바닥 쪽으로 내림 | 40°      |
| 외번 — 바깥쪽으로 기울임  | 20°      |
| 내번 — 안쪽으로 기울임   | 30°      |
| **합계**          | **110°** |

따라서 기본 계산은 아주 단순합니다.

\\[ 실제ROM=배굴+척굴+외번+내번 \\]

그리고

\\[ \boxed{운동제한율(\\%)=\frac{110-실제ROM}{110}\times100} \\]

### 2. 보훈 발목 장해 기준

현재 국가유공자 상이등급 기준에서는 **한쪽 발목 하나만 장해가 있는 경우** 다음처럼 이해하면 됩니다. [법제처](https://www.law.go.kr/flDownload.do?bylClsCd=110201\&flSeq=159176887\&gubun=\&utm_source=chatgpt.com)

| ROM 제한율    | 쉽게 말하면         | 보훈 기준          |
| ---------- | -------------- | -------------- |
| **25% 미만** | 정상의 75% 넘게 움직임 | ROM만으로는 기준 미달  |
| **25% 이상** | 1/4 이상 못 움직임   | **7급 8122**    |
| **50% 이상** | 절반 이상 못 움직임    | **6급 2항 8121** |
| **75% 이상** | 3/4 이상 못 움직임   | **6급 1항 8117** |

즉 프로그램에서는 사실상 이렇게 만들면 됩니다.
```
제한율 < 25%
→ ROM 기준 등급 미달

25% ≤ 제한율 < 50%
→ 경도 기능장애
→ 7급 8122

50% ≤ 제한율 < 75%
→ 중등도 기능장애
→ 6급 2항 8121

75% ≤ 제한율
→ 고도 기능장애
→ 6급 1항 8117
```

## 3. 각도로 바꾸면 더 간단함

정상 총 ROM이 \*\*110°\*\*이므로 역산하면:

### 25% 제한

\\[ 110\times0.75=82.5° \\]

따라서 실제 움직임이 **82.5° 이하**이면 25% 이상 제한입니다.

### 50% 제한

\\[ 110\times0.50=55° \\]

실제 움직임이 **55° 이하** → 50% 이상 제한.

### 75% 제한

\\[ 110\times0.25=27.5° \\]

실제 움직임이 **27.5° 이하** → 75% 이상 제한.

그래서 프로그램용으로 줄이면:

\\[ \boxed{ ROM\le27.5° \Rightarrow 6급1항 } \\]\\[ \boxed{ 27.5°\<ROM\le55° \Rightarrow 6급2항 } \\]\\[ \boxed{ 55°\<ROM\le82.5° \Rightarrow 7급 } \\]\\[ \boxed{ ROM>82.5° \Rightarrow ROM기준 등급미달 } \\]

## 4. 실제 예시

환자의 측정값이

- 배굴 10°
- 척굴 20°
- 외번 10°
- 내번 15°

라면,

\\[ 실제ROM=10+20+10+15=55° \\]

정상은 110°이므로

\\[ \frac{110-55}{110}\times100 =\boxed{50\\%} \\]

따라서

**운동가능영역 50% 제한 → 한쪽 발목 기준 6급 2항 8121**에 해당하는 구조입니다. 국가법령정보센터의 실제 심판례에서도 발목 운동각을 합산하여 정상 110°와 비교하는 방식이 확인됩니다. [법제처](https://www.law.go.kr/DRF/lawService.do?ID=253349\&OC=unicpla\&mobileYn=Y\&target=decc\&type=HTML\&utm_source=chatgpt.com)

### 중요한 예외

보훈에서는 **ROM만 보는 게 아닙니다.** 예를 들어 한쪽 관절의 ROM 제한이 25%에 못 미쳐도, 적절한 치료 후 **관절 인대 불안정성이 10mm 이상**이거나 영상검사에서 **KL grade III 이상의 퇴행성 변화**가 인정되면 7급 8122 판단 요소가 될 수 있습니다. [법제처](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110201\&flSeq=156434101\&gubun=\&utm_source=chatgpt.com)

그래서 네 계산기의 핵심 로직은 \*\*`4개 각도 입력 → 총 ROM → 제한율 계산 → 25/50/75% 임계값 비교 → 상이등급 표시`\*\*로 잡으면 됩니다.
