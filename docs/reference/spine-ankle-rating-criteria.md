## 2. 발목 관절 — 보훈 상이등급

발목은 다리의 주요 관절 중 하나로 다뤄지며, 단일 발목관절만 놓고 보면 다음 기준들이 핵심입니다.

| 보훈 등급          | 발목 관련 판정 기준                                                                                                                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **6급 1항 8117** | 관절 운동가능범위가 정상의 **4분의 3 이상 제한**된 경우, 또는 **인공관절 재치환술**을 받은 경우. [법제처](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110201\&flSeq=156423917\&gubun=)                                                                |
| **6급 2항 8121** | 운동가능범위가 정상의 **2분의 1 이상 제한**된 경우, 또는 **인공관절을 삽입·치환**한 경우. [법제처](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110201\&flSeq=156423917\&gubun=)                                                                    |
| **7급 8122**    | 운동범위가 정상의 **4분의 1 이상 제한**, 또는 적절한 치료 후에도 인대손상으로 **10mm 이상 동요**, 또는 방사선상 **Kellgren-Lawrence Grade III 이상** 퇴행성 변화 등이 있는 경우. [법제처](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110201\&flSeq=156423917\&gubun=) |

발목 정상 운동범위는 기준상 배굴 20°, 저굴 40°, 내번 30°, 외번 20°로 총 \*\*110°\*\*를 기준으로 볼 수 있습니다. [법제처](https://www.law.go.kr/DRF/lawService.do?ID=253349\&OC=unicpla\&mobileYn=Y\&target=decc\&type=HTML\&utm_source=chatgpt.com)

따라서 운동범위만 계산하면 다음처럼 환산할 수 있습니다. 이것은 법령에 그대로 적힌 숫자가 아니라 **110°에 비율을 적용한 계산값**입니다.

- 4분의 3 이상 제한 → 남은 운동범위 **27.5° 이하**
- 2분의 1 이상 제한 → **55° 이하**
- 4분의 1 이상 제한 → **82.5° 이하**

## 3. 발목 — 보험 후유장해 지급률

금융감독원 표준약관에서는 발목을 고관절·무릎관절과 함께 **다리의 3대 관절**에 포함합니다. [법제처](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=200201\&flNm=%5B%EB%B3%84%ED%91%9C+15%5D+%ED%91%9C%EC%A4%80%EC%95%BD%EA%B4%80%28%EC%A0%9C5-13%EC%A1%B0%EC%A0%9C1%ED%95%AD%EA%B4%80%EB%A0%A8%29\&flSeq=153808295)

| **관절 기능을 완전히 잃었을 때** | **30%** | 완전강직 또는 신경손상 등으로 근력이 MMT 0인 경우 등. [법제처](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=200201\&flNm=%5B%EB%B3%84%ED%91%9C+15%5D+%ED%91%9C%EC%A4%80%EC%95%BD%EA%B4%80%28%EC%A0%9C5-13%EC%A1%B0%EC%A0%9C1%ED%95%AD%EA%B4%80%EB%A0%A8%29\&flSeq=153808295)                                    |

[법제처](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=200201\&flNm=%5B%EB%B3%84%ED%91%9C+15%5D+%ED%91%9C%EC%A4%80%EC%95%BD%EA%B4%80%28%EC%A0%9C5-13%EC%A1%B0%EC%A0%9C1%ED%95%AD%EA%B4%80%EB%A0%A8%29\&flSeq=153808295)                        |
| **약간의 장해**           | **5%**  | 운동가능범위가 정상의 **3/4 이하**, 동요 **5mm 이상** 등의 경우. [법제처](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=200201\&flNm=%5B%EB%B3%84%ED%91%9C+15%5D+%ED%91%9C%EC%A4%80%EC%95%BD%EA%B4%80%28%EC%A0%9C5-13%EC%A1%B0%EC%A0%9C1%ED%95%AD%EA%B4%80%EB%A0%A8%29\&flSeq=153808295)                         |

발목 총 정상 운동범위를 110°로 환산하면 보험상 ROM 기준도 다음과 같이 볼 수 있습니다.

| 남은 ROM     | 보훈            | 보험      |
| ---------- | ------------- | ------- |
| **≤27.5°** | 6급 1항 해당 가능   | **20%** |
| **≤55°**   | 6급 2항 해당 가능   | **10%** |
| **≤82.5°** | 7급 해당 가능      | **5%**  |
| 완전강직 등     | 별도 상이등급 기준 검토 | **30%** |

즉 **발목의 ROM 비율 자체는 두 제도가 상당히 비슷한 계단식 기준**을 사용하지만, 보훈은 상이등급으로, 보험은 5·10·20·30% 지급률로 결과를 표현합니다. 또한 인공관절, 불안정성, 퇴행성 변화 같은 추가 조건은 두 제도의 세부 규정이 서로 다릅니다. [법제처](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110201\&flSeq=156423917\&gubun=)
